# @pripo/sdk

This package currently contains generated ABI constants. `marketAbi` and `marginVaultAbi` describe the implemented runtime contracts, including operator-proof overloads, vault administration, and initialization.

```ts
import { marketAbi, marginVaultAbi } from "@pripo/sdk/abis";
```

`marketCoreAbi` and `marginVaultInterfaceAbi` are the smaller integration interfaces. `plannedMarketAbi` is the future Phase 1 interface, including resolver settlement declarations and wind-down that are not implemented yet. `maxOpenable`, `liquidationPrice` and `liquidationPriceInfo` are implemented in the runtime and core ABIs. `liquidate` is implemented in `marketAbi` and `marketCoreAbi`, including paired ADL and forced whole-market settlement. The two-argument overload ranks the complete book and matches up to 64 candidates; the explicit overload accepts unique eligible candidates sorted by score. A valid insufficient list leaves `AdlPending` when the full book remains sufficient. Anyone can call `continueAdl(user, candidates)` immediately, or `completeAdl(user, maxIterations)` after the fixed pending window (1–64 slot visits per call). Only a fresh full-book eligible-size check authorizes settlement. Greedy chunks use fixed entry/value schedules and a reserved one-quote-wei payment for zero booked profit; exhausted allowance emits `AdlZeroProfit`. `insuranceBackstopAbi` and `insuranceBackstopInterfaceAbi` expose the controller. The factory’s concrete `marketFactoryAbi` now includes governance, feed escrow and the oracle-update creation overload; `marketFactoryInterfaceAbi` is its smaller integration interface. Resolver, price-source and shared-error interfaces are also exported.

The vault ABI includes reserve/deficit views, `fundProtocolReserve`, `recapitalize`, WAD-denominated `contributeToDeficit`, bounded `allocateProtocolFees`, and gated treasury claims. Token contributions use raw six-decimal USDC; reserve, fee and deficit balances use WAD. Allocation accepts 1–32 queue entries per call and may leave fees awaiting a later batch. Global token contributions also have a 32-entry allocation limit and revert atomically when more processing is required. `requireOpenAllowed(market)` checks reserve admission, deficit and floor gates; quote calculations alone do not guarantee an open can execute. `finalizeSettlement` is a trusted-market custody hook used atomically by the forced-settlement engine; it is not a user entry point.

The market exposes `positionCount()` and `positionAccounts(offset, limit)` for its bounded book of at most 128 nonempty positions. Page limits above 256 revert. Slots remain stable until close; pages include zero-address holes, while `positionCount()` counts live accounts. Read pages at the same block and skip holes. Increasing an existing position does not consume another slot; opens and increases pause while any ADL is pending.

`maxOpenable(user, isLong)` returns additional signed owner capacity, including the opening fee, previewed funding, post-trade caps and market/vault/book gates. Operators still need their policy/proof check, and the eventual send still needs a valid oracle update and limit price. The result is exact at the read block; pin related reads and simulate the send.

`liquidationPriceInfo(user)` returns `(price, referenceKind, reason)`. References are none/index/TWAP = 0/1/2. Reasons are threshold/no position/pending ADL/inactive/funding-capacity binding/negative collateral/already unhealthy TWAP/no crossing = 0–7 in that order. `liquidationPrice` returns only the price. A zero price never establishes safety: use the reason and `health`. Index thresholds are inclusive (long at/below, short at/above); a mathematical threshold may exceed the oracle's accepted range. A TWAP threshold is the nearest adverse reachable crossing with other inputs fixed; rounded PnL can have more than one crossing. [Exact semantics](../../docs/implementation-notes.md#exact-risk-views) apply to both views.

`pendingAdl(user)`, `pendingAdlCount()` and `adlEligibleSize(user)` expose progress and current eligibility. The pending struct’s `reservedC` is original coverage; the `AdlPending` event’s field is the remaining reservation. Vault `adlReservation`, `adlReserved` and `adlReservedTotal` report the actual reserved cash. `consumedC` is net provisional loss coverage and can fall after relief or margin replacement; it excludes top-ups. Pending owners may add margin but cannot close or remove it. Funding stays frozen until the last pending resolves.

`AutoDeleveraged` now reports winner, loser, signed winner size, actual shared chunk value and removed winner entry. `AdlInsufficient` reports the fresh complete-book proof. `ForcedSettlement` reports TWAP, pre-haircut shortfall and deepest capital step. Regenerate event decoders for these changed signatures. The new config fields are `adlPendingWindow` and `maxPositionsPerMarket`; the position tuple adds `slot` and `adlPending`.

`settlementQuote()` previews whole-book valuation at the 300-block TWAP, including pending funding, profit haircuts and the remaining capital requirement before local fees/backstop/reserve. It excludes a future keeper penalty and oracle update and does not establish trigger eligibility. `settlementInfo()` exposes the stored price, exact haircut and eligible profits after settlement. Settlement freezes funding and permanently ends trading on that market. Terminal source events are emitted by both market and vault; see the implementation notes.

Exports are TypeScript source for consumption by a TypeScript-aware bundler. Regenerate them with `make abi` from the repository root, or run `npm run generate` here after a Foundry build. Transaction simulation, oracle updates, signing, and typed trading methods are the next SDK work. Operator callers should use `quoteOpenFor(user,size)` and pass a market proof when their policy requires one; expiry is denominated in blocks.

`pythAdapterAbi`, `nullAdapterAbi` and `feeSweeperAbi` describe the implemented adapters and batch sweeper. Pyth updates use ABI-encoded `bytes[]`; query `updateFee(update)` and send exactly that native fee. For creation, approve the factory to spend `seedBond` raw USDC, use its canonical null adapter/feed zero for oracle-less markets, or a listed external feed. `createMarket(params, update)` can apply the pull update in the creation transaction. Verify `predictAddress` immediately before sending, since activation of a new implementation changes predictions for unused symbols.

Listing bonds also use raw USDC. Refunds always pay the original lister; slashing destination is immutable deployment configuration. `FeeSweeper.sweep(markets)` may successfully repay/refill without any treasury payment. Each batch accepts at most 32 distinct registered markets; `allocate(markets, maxEntries)` lets keepers use a smaller queue-processing budget.

`fundingCapacity(user)` returns the signed cap index, protected trading collateral and available payer capacity, in internal WAD units. `fundingLimit(isLong)` returns that side's minimum key and account; an empty side returns the zero address and `int256.max`. `fundingBinding()` includes a clamp visible in the funding preview before checkpointing. A binding account is liquidatable even with healthy equity. Both indexes stay frozen until that account closes or gains usable capacity; unrelated updates cannot resume funding. A position at its protected collateral floor has no funding headroom.

The reserve floor is now fixed at 10,000 USDC; the former funding reserve budgets are zero on new admissions and their deprecated storage getters remain. The removed `RESERVE_BLOCKS` getter is no longer part of the runtime ABI. Tiny partial closes that would spend collateral backing the residual position revert; simulate execution in addition to reading numerical quotes.
